## 🛟 Troubleshooting

### Problem: agentry won't start
- Make sure Docker Desktop is running (look for the whale icon in your taskbar)
- Close and reopen agentry
- Restart your computer and try again

### Problem: Web page won't load
- Check that the address is exactly `http://localhost:3000` (with no "s" in http)
- Wait 30 seconds and refresh the page
- Check if your firewall is blocking local connections

### Problem: Slow responses
- Make sure you have a stable internet connection
- Close other programs that use a lot of memory
- Wait a few moments - AI responses can take 5-10 seconds
